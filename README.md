# Bank Term Deposit Prediction Using Machine Learning

## Project Overview
This project uses machine learning to predict whether a bank customer is likely to subscribe to a term deposit.

## Objectives
- Analyze customer and marketing data.
- Perform data cleaning and exploratory data analysis (EDA).
- Train machine learning classification models.
- Evaluate models using performance metrics.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Machine Learning

## Project Files
- Python source code: `Bank_Term_Deposit_Prediction_Complete_Code.py`
- Project report: `Bank_Term_Deposit_Prediction_Final_Report.pdf`

## Workflow
1. Load the dataset.
2. Clean and prepare the data.
3. Perform exploratory data analysis.
4. Train machine learning models.
5. Evaluate model performance.

## Evaluation Metrics
Accuracy, Precision, Recall, F1-score, and ROC-AUC.

## How to Run
1. Install Python and the required libraries.
2. Download the Python file from this repository.
3. Update the dataset file path in the code.
4. Run the Python script.
